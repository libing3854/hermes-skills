## winshare命令（~/bin/winshare）
```bash
winshare ls              # 列出根目录
winshare cd 电子书        # 列出子目录
winshare get 远程文件 本地路径   # 下载
winshare put 本地文件 远程路径   # 上传
winshare shell           # 交互模式
```
