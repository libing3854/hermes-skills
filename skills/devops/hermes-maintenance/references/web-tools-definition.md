# Web工具定义

## 冰哥的"web工具"特指

在冰哥的语境中，"web工具" = 两个服务：

### 1. Hermes Dashboard
- 端口：9119
- 启动：`hermes dashboard --port 9119 --no-open`
- 用途：Hermes管理界面

### 2. Hermes Workspace  
- 端口：3000
- 代码：`/Users/libing/hermes-workspace/`
- 启动：`cd hermes-workspace && vite dev --host 127.0.0.1 --port 3000`
- 用途：工作空间界面

## 不是"web工具"的
- 端口8080的dashboard — ❌ 不是冰哥要的
- web_search工具 — ❌ 这是搜索功能，不是界面
- web_extract工具 — ❌ 这是内容提取，不是界面
