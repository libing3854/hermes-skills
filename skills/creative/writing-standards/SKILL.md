# 写作规范和质量标准

## 字数标准

### 基本要求
- **每章字数**: 4500-5500字（纯中文字/汉字）
- **上限**: 不超过6000字
- **计数方式**: 纯中文字（汉字），不含标点符号、空格、英文
- **标准来源**: 网文平台（如番茄小说）使用纯汉字计数，"有效文字为准小说网站就是这样的"

### ⚠️ 三种统计方式差异巨大
| 统计方法 | Python代码 | 说明 | 差异 |
|----------|-----------|------|------|
| 纯中文字 | `len(re.findall(r'[\u4e00-\u9fff]', text))` | **网文平台标准** | 基准 |
| 中文+中文标点 | `len(re.findall(r'[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef]', text))` | 含中文标点 | +10-15% |
| 所有非空白字符 | `len(re.sub(r'\s', '', text))` | 含ASCII/英文 | +20-30% |

**实例**: 同一段文字，纯中文字4,023 vs 中文+中文标点4,517 vs 非空白字符4,780

### 验证方法
```python
import re
with open("chapter.md", encoding="utf-8") as f:
    text = f.read()
chinese_chars = re.findall(r'[\u4e00-\u9fff]', text)
print(f"中文字数: {len(chinese_chars)}")
```

## 禁用词（0次）

### 绝对禁止
- "仿佛"
- "深吸一口气"
- "不由得"

### ⚠️ 变体也要禁止（2026-06-11 审核发现）
- "深吸了一口气" — "深吸一口气"的变体，出现3次（第256/257/260章）
- 任何包含"深吸"的表达都应替换为："呼出一口气""长长地吐息""胸口起伏了一下"

### 验证方法
```bash
grep -E "仿佛|深吸一口气|深吸了一口气|不由得" chapter.md
```

## AI高频词限制

### 限制标准
| 词汇 | 限制 | 说明 |
|------|------|------|
| "像"比喻 | 每章≤10次 | 比喻词（2026-06-14从15收紧，实测AI单章可达49次） |
| "如同" | 每章≤3次 | "像"的替代品，扩写时容易过度使用 |
| "仿若" | 每章≤1次 | AI典型替代词（替代"仿佛""好像"），2026-06-16发现288章×6次 |
| "某种" | 每章≤3次 | 模糊指代（2026-06-16从≤1次放宽到≤3次，实测合理使用可达3次） |
| "一种" | 每章≤3次 | 模糊指代（2026-06-18发现303章22次、304章18次，从≤5收紧到≤3） |
| "这份" | 每章≤3次 | AI"定义性解释"风格信号词（2026-06-18发现303章22次、304章18次）。表现为"这份...状态/方式/感觉/光/温度"固定搭配 |
| "不是…而是…" | 每章≤3次 | AI过度解释模式（2026-06-18发现301-304章平均5次/章），改为陈述句 |
| "回荡" | 每章≤2次 | AI倾向过度使用（2026-06-16发现288章×5次），替换为"回响""盘旋""传递" |
| "微微/缓缓" | 每章合计≤2次 | 程度副词 |

### ⚠️ AI替换规避陷阱（重要）
AI会把禁用词替换为同义词来规避限制，但结构模式不变：
- "像" → "如同"（第282章出现10次）
- "仿佛" → "仿若"（第288章出现6次，是"仿佛"的变体）
- "回响/传递" → "回荡"（第288章出现5次）
- 审核时需同时检查替换词，不能只看原始禁用词

### 验证方法
```bash
grep -c "像" chapter.md        # 检查"像"比喻次数
grep -c "如同" chapter.md      # 检查"如同"次数
grep -c "仿若" chapter.md      # 检查"仿若"次数（AI替代"仿佛"）
grep -c "某种" chapter.md      # 检查"某种"次数
grep -c "一种" chapter.md      # 检查"一种"次数（≤3次）
grep -c "这份" chapter.md      # 检查"这份"次数（≤3次，AI定义性解释信号）
grep -c "回荡" chapter.md      # 检查"回荡"次数
grep -cE "微微|缓缓" chapter.md  # 检查微微/缓缓合计
grep -cE "不是.*而是" chapter.md  # 检查"不是…而是…"模式（≤3次）
```

## 审核标准

### 评分维度
1. **字数控制** (15%) - 是否在4500-5500字范围
2. **AI高频词** (20%) - 像/某种/微微缓缓是否超标
3. **禁用词** (15%) - 是否有禁用词出现
4. **剧情推进** (20%) - 情节是否连贯、有推进
5. **人物塑造** (15%) - 角色是否立体、有成长
6. **逻辑连贯** (10%) - 上下文是否衔接自然
7. **内容质量** (5%) - 文笔、氛围、细节

### 评分等级
- **A (90-100)**: 优秀，直接通过
- **B (80-89)**: 良好，小问题可修改
- **C (70-79)**: 及格，需要较大修改
- **D (60-69)**: 不及格，需要重写
- **F (<60)**: 严重问题，需要重新评估

## 常见问题

### "像"比喻过多
**问题**: AI写作习惯性使用"像...一样"句式
**解决**: 保留核心比喻，删除冗余表达

### ⚠️ 扩写导致AI高频词回潮（严重 - 2026-06-13 发现）
**问题**: 当章节字数不足需要扩写时，AI会大量引入「像」「某种」「如同」等比喻词来填充内容，导致这些高频词从达标状态飙升至严重超标。
**实例**: 第277-283章扩写前「像」31次、某种2次（达标）→ 扩写后「像」151次、某种39次（严重超标）。
**解决**:
1. 扩写任务body中必须明确约束AI高频词上限
2. 扩写后必须立即做AI高频词检查
3. 用脚本批量削减：保留前15个「像」，其余删除；「某种」只保留1次，其余删除
4. 重点关注「如同」作为「像」的替代品（第280章出现26次）

### ⚠️ 「像某种」组合（AI高频标志 - 2026-06-11 审核发现）
**问题**: "像某种有生命的东西""像某种寄生的藤蔓"等组合是AI写作的典型标志
**解决**: 将"像某种"直接替换为"如同"或删除"像"保留名词描述
**第256-262章出现5处**: "像某种有生命的东西""像某种寄生的藤蔓""像某种缓慢的、有生命的物质""像某种巨大的、活着的神经系统""像某种寄生物"

### 模板化句式
**问题**: "不是A，是B"、"不是X，而是Y"等排比碎片化
**解决**: 合并为流畅的长句，保留核心含义

### 跨章模板结尾（严重 - 2026-06-11 审核发现）
**问题**: 连续多章使用几乎相同的结尾结构（如"像一扇关上的门。像一只缓缓闭上的眼睛。像——"）
**解决**: 每章结尾必须不同，禁止跨章复用相同结尾句式

### 中文/点号命名规则
**问题**: Profile名称包含中文或点号会导致 `spawn_failed: Invalid profile name`
**解决**: 名称必须匹配 `[a-z0-9][a-z0-9_-]{0,63}`，如 `shanli-agnes20flash`（不用 `shanli-agnes2.0flash`）

### 重复描写
**问题**: 同一场景/动作在不同章节重复出现
**解决**: 保留最精彩的版本，其他简化或删除

### ⚠️ 破折号（——）极度异常（2026-06-16 发现）
**问题**: AI写作在词内插入破折号，形成"审——判""深——海""共——鸣"等异常格式。同时每章破折号总量可达1000+次，远超正常水平。
**实例**: 第280-289章审核中，GPT-5.5报告显示：
- 第280章：1135个破折号/2646汉字 = 429次/千字
- 第289章：1598个破折号/1997汉字 = 800次/千字
- 正常水平应为 <10次/千字
**解决**:
1. 正常破折号（——）每章≤5次，用于语义转折或强调
2. 绝对禁止词内破折号（审——判、深——海、共——鸣）
3. 用正常标点替代：句号、逗号、省略号
4. 扩写/重写时特别注意：AI倾向于用破折号制造"节奏感"，实际破坏阅读体验

### ⚠️ 扩写不等于加内容（2026-06-16 教训）
**问题**: 当章节字数不足时，简单"扩写"往往只是加更多破折号和碎片化短句，实际汉字数没有增加。
**实例**: 第280-289章重写任务声称完成，但字数从平均2300字只提升到平均2800字，远低于4500字目标。
**解决**:
1. 扩写必须是实质性内容增加（新场景、新对话、新描写）
2. 每章扩写后必须用Python验证纯汉字数
3. 如果扩写后仍不达标，需要完全重写而非修补

### ⚠️ 风格级高频词（2026-06-15 审核发现）
**问题**: 某些形容词/描述词虽然不在标准禁用词列表中，但AI倾向于过度使用，导致文风单调。
**实例**: 第五卷审核中，莉莉标记了以下问题：
- "透明"×8次/章（第20章）
- "清晰"×4次/章（第15章）
- "柔和"×4次/章（第15章）
- "闪烁"×3次/章（第20章）
- "精致"×3次/章（第20章）
**解决**: 这类词每章合计≤5次。审核时如果发现单一描述词出现3次以上，应标记为P1建议修改。
**注意**: 这些不是绝对禁用词，不需要清零，但需要控制频率避免文风单调。

## 审核流程

1. **初审**: 闪莉写作完成后，莉莉逐章审核
2. **评分**: 按7个维度打分，给出综合评级
3. **问题清单**: 列出所有需要修改的问题
4. **修改建议**: 针对每个问题给出具体修改方案
5. **复审**: 闪莉修改后，莉莉再次审核
6. **通过**: 达到B级以上（80分以上）通过
