## 新增教训

### 教训1：修改任务引入新问题（P0）🆕

**症状**：修改任务扩写内容后，"像"比喻从79次飙升到135次（+72%）

**根因**：
- 修改任务要求"补充字数至5000字"
- 闪莉扩写时大量使用"像"比喻来填充内容

**解决方案**：
1. 修改任务body中明确"高频词约束"：扩写时不要增加"像"比喻
2. 修改后安排莉莉再次审核，检查是否引入新问题
3. 高频词削减可以作为独立任务单独处理

### 教训2：修改任务应按问题类型拆分（P0）🆕

**拆分示例**（第八批）：
```
任务1（闪莉）：两稿拼接修复 + 字数补充
任务2（莉莉）："某种"批量替换
任务3（莉莉）："像"比喻削减
任务4（莉莉）：大纲偏差修复
```

### 教训3：工作流确认优先于执行（P0）🆕

- 任何涉及任务创建/修改的操作，必须先等冰哥确认
- 不要假设冰哥的意图，宁可多问一句

### 教训4：莉莉执行高频词削减效率极高（P1）🆕

- 莉莉执行"像"比喻削减：194秒（3分钟）
- 从135次削减到17次（削减率87%）
- 高频词削减适合交给莉莉，闪莉更适合写正文

### 教训5：章节拆分必须先扩充再分割（P0）🆕（2026-06-09）

**场景**：章节字数不足，需要拆分成两章（每章≥4500字）

**错误做法**：直接拆分
- 当前5043字，直接拆成两章 → 每章只有2500字，远低于4500目标

**正确做法**：先扩充预留分割位置，再分割
```
Step 1: 确认当前字数和目标字数
  当前5043字，目标9000字（每章4500字）

Step 2: 找到自然分割点（通常在场景切换处）
  第131行附近："从这里开始——我们需要小心。"

Step 3: 扩充上半部分（+2000字）
  增加环境描写、角色互动、细节观察

Step 4: 扩充下半部分（+2000字）
  增加下降过程、核心描写、情感反应

Step 5: 在分割点标记
  插入分割标记，明确上/下半部分边界

Step 6: 拆分成两个文件
  上半部分：第221章_灯塔之下（上）.md
  下半部分：第222章_灯塔之下（下）.md

Step 7: 后续章节改名
  原第222章_仪式.md → 第223章_仪式.md
  （所有后续章节号+1）

Step 8: 验证每章字数≥4500字
```

**关键原则**：
1. 先扩充再分割，不要直接拆
2. 分割点选在自然场景切换处
3. 扩充内容要保持角色一致性和去AI味风格
4. 后续所有章节号需要顺延

**验证方法**：
```bash
wc -m 第221章_灯塔之下（上）.md 第222章_灯塔之下（下）.md
# 每章应≥4500字
```
