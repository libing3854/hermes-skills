# Fanqie Recommendation Algorithm Metrics

> 番茄小说推荐机制核心指标，基于2026-06-10研究整理。

## 核心指标

番茄小说是**纯粹的数据导向**，不像起点有人工编辑推荐，完全靠算法。

| 指标 | 说明 | 重要性 |
|------|------|:------:|
| **三日留存率** | 读者看完第一章后，三天内是否继续追读 | ⭐⭐⭐⭐⭐ |
| **追读率** | 每天有多少读者继续读下一章 | ⭐⭐⭐⭐⭐ |
| **完读率** | 读者是否读完当前章节 | ⭐⭐⭐⭐ |
| **互动率** | 评论、点赞、收藏等 | ⭐⭐⭐ |
| **阅读时长** | 读者在每章停留的时间 | ⭐⭐⭐ |

## 推荐流程

```
新书发布 → 达到一定字数 → 进入测试推荐期
    ↓ 数据达标
逐级放量（小量测试→数据达标→逐级放量）
    ↓ 数据回落
停量或减少推荐
```

## 推荐不通过的常见原因

### 数据层面（最常见）
1. **三日留存率低** — 开篇不够吸引人，前3章节奏太慢
2. **追读率低** — 章节结尾没有悬念，读者没有继续读的动力
3. **完读率低** — 章节太长（超过5000字读者容易疲劳），内容注水
4. **互动率低** — 没有引发读者讨论的情节，角色塑造单薄

### 内容层面
5. **AI痕迹明显** — "微微"、"缓缓"、"某种"等高频词
6. **节奏问题** — 流水账叙事，衔接断裂，空洞升华
7. **人设问题** — 人物形象单薄，前后不一致

### 平台规范层面
8. **违反平台红线** — 政治敏感、暴力、色情等
9. **恶意水文** — 批量重复内容，节奏异常
10. **作弊行为** — 刷评论、刷收藏，触发风控降权

## 对写作的启示

1. **开篇前3章决定性** — 必须有核心冲突或金手指展示
2. **每章结尾必须有钩子** — 悬念/反转/期待感
3. **控制章节长度** — 4500-5500字为宜，超过5000字读者容易疲劳
4. **避免AI痕迹** — 高频词控制，保持自然文风
5. **不要刷数据** — 平台会检测，触发降权

## 字数节点

平台设置了字数完读率，10万字、20万字等关键节点会有流量推荐变化。在这些节点前确保内容质量。

## 外部流量注意

通过抖音短视频等外部渠道拉新，如果留存率低于20%，外部流量反而拉低权重。
