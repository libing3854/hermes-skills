# 章节拆分工作流

> 实战案例来源：《我在深渊开事务所》第四卷第221章和第223章拆分

## 触发条件

- 单章字数 > 8000字（目标6000字的1.3倍以上）

## 拆分流程

1. 分析章节结构，识别关键节点（场景/情节/情感转换）
2. 确定拆分点（优先级：场景转换 > 情节转换 > 情感转换）
3. 评估字数分配（每章目标4500-5000字，总字数≥9000字）
4. 如果字数不够，先扩充到目标总字数
5. 执行拆分：备份→head/tail→更新标题
6. 验证：每章≥4500字，情节完整，角色一致

## 拆分点选择优先级

1. 场景转换（最佳）：如"旧船坞区的竖井旁边"
2. 情节转换（次佳）：如"仪式是——喂养"
3. 情感转换（可用）：如"杰克闭上了眼睛"

## 内容匀分技巧（2026-06-09 实战）

当拆分后两章字数不均匀时（如一章3980字、另一章8755字），不要强行扩充短章——而是**从长章移动内容到短章**：

```bash
# 从下半部分提取要移动的内容（如第374-410行）
sed -n '374,410p' 下半部分.md > /tmp/move_content.md

# 将内容添加到上半部分结尾
cat /tmp/move_content.md >> 上半部分.md

# 从下半部分删除已移动的内容
sed -i '' '374,410d' 下半部分.md
```

**选择移动内容的原则**：
1. 优先移动**独立场景**（如角色对话、回忆片段），不破坏主线节奏
2. 移动后上半部分的结尾要自然（不能在句子中间截断）
3. 移动后下半部分的开头要能衔接（读一下移动后的首行是否通顺）
4. 每次移动后验证两章字数，直到都≥4500字

**实战数据（第223章拆分）**：
- 初始：上半3980字 / 下半8755字（不均匀）
- 第1次移动37行：上半4394字 / 下半8341字
- 第2次移动57行：上半5002字 / 下半7733字（达标）

## 字数标准

- **底线**：每章≥4500字（冰哥2026-06-09确认）
- **目标**：每章4500-5000字
- **拆分后**：两章都必须≥4500字

## 注意事项

- 先扩充再拆分（字数不够时）
- 拆分点要自然，不要在句子中间拆
- 备份原文件
- 后续章节编号需要更新
- 拆分后如果字数不均匀，用内容匀分技巧调整
