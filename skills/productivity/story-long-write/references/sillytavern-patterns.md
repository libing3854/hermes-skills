# SillyTavern 写作模式参考

> 从 SillyTavern（酒馆）提示词系统中提取的写作辅助模式。
> 这些模式已被转化为独立的辅助技能，本文件仅做概念参考。

## 核心模式

### 1. 作者笔记（Author's Note）→ writing-guardrails

SillyTavern 的创作者笔记可以每 N 条消息自动插入一段指导语，持续引导 AI 行为。

**我们的实现：** 不是自动注入，而是嵌入看板任务 body 或审核流程中的**自查清单**。
- 每章写完后自查（风格/禁用词/角色一致性）
- 每 5 章做阶段性检查（连贯性/风格漂移/字数）
- 跨卷检查（引用 cross-volume-continuity.md）

### 2. 角色卡示范对话 → character-dialogue-template

SillyTavern 的角色卡包含"示范对话"段落，展示角色如何说话。AI 会模仿这些示例。

**我们的实现：** 每个角色文件（`设定/角色/角色名.md`）必须包含"示范对话"段落，至少 3 段，覆盖该角色最常见的说话场景。

**编写技巧：**
- 具体胜于抽象（"说重点"比"说话很直接"好）
- 展示情绪变化（平静/愤怒/悲伤各一段）
- 锁定口头禅和用词

### 3. 动态世界信息 → context-trigger

SillyTavern 的世界信息可以根据对话内容自动激活（关键词触发）。

**我们的实现：** 不是自动触发，而是在细纲和看板任务 body 中**手动标注**本章涉及的角色/地点/伏笔/设定。

### 4. 深度分层（Chat Depth）

SillyTavern 按消息位置分层：深度 0-1 直接影响当前回复，深度 5+ 影响整体方向。

**我们的实现：** 在看板任务 body 中分层标注上下文：
- 必读（深度 0-1）：上一章结尾 + 本章细纲
- 重要（深度 2-5）：角色状态 + 相关伏笔
- 参考（深度 6+）：世界观设定 + 历史事件

### 5. 预设系统（Presets）→ writing-preset

SillyTavern 的预设系统可以一键加载上下文模板 + 指令模板 + 系统提示 + 采样器设置。

**我们的实现：** 看板任务 body 的标准模板库，3 种场景模板（长篇日更/短篇/大纲优化）。

## 与现有技能的映射

| SillyTavern 模式 | 我们的技能 | 定位 |
|------------------|-----------|------|
| 创作者笔记 | writing-guardrails | 自查清单 |
| 角色卡示范对话 | character-dialogue-template | 角色文件格式 |
| 动态世界信息 | context-trigger | 上下文标注 |
| 预设系统 | writing-preset | 看板任务模板 |
| 系统提示 | story-long-write | 主流程引擎 |

## 设计原则

**核心教训（大莉M审核 2026-06-08）：** 不要把愿望当成机制。Hermes 的 skill 系统是静态文本加载，没有自动注入、自动触发、连锁调用等能力。所有技能应该提供**模板/清单/格式**，而非描述不存在的自动化。
