# 看板任务深度审核实例（2026-05-31）

## 背景

冰哥安排闪莉写《我在深渊开事务所》第三卷（第067-161章，95章）。创建看板任务后，派大莉M（deepseek-v4-pro）审核任务规格，发现了多个致命问题。

## 发现的致命问题

### 1. 角色生死状态跨文件矛盾 🔴
- **伏笔总览**：乔治已牺牲（第059章穹顶之战）
- **第三卷大纲**：第069-071章安排乔治参与精神病院调查
- **正文验证**：第059章有乔治葬礼，第066章无乔治
- **修复**：将大纲中乔治的所有戏份替换为玛拉/凯尔/莉迪亚

### 2. 凯尔提前登场矛盾 🔴
- **大纲第069章**：凯尔参与团队分工
- **大纲卷级概览**：第089-097章才是"新队友凯尔加入"
- **修复**：删除第069章凯尔分工条目，或调整为其他队友

### 3. 大纲标注元素遗漏 🟡
- 大纲中有【E-城市电台】【A-底层群像】【F-队友日常互动】【B-杰克童年回忆】等结构性标注
- 任务body中未提及这些元素的处理方式
- **修复**：在任务body中补充标注处理说明

### 4. 凯尔双重指派 🔴
- 第090章：凯尔同时出现在"前往天空之城"和"留守协助维拉"名单中
- 第139章：凯尔同时出现在A组和B组
- **修复**：根据后续剧情确认正确分组

### 5. 章节编号跨文件不一致 🔴
- 伏笔总览说第067章属于第二卷（第023-067章）
- 第三卷大纲说第067章属于第三卷（第067-161章）
- **修复**：修改伏笔总览为第023-066章

## 审核流程

```
创建看板任务 → 大莉M审核任务规格 → 发现问题 → 修复 → 再审核 → 通过 → dispatch
```

## 关键教训

1. **角色生死状态必须跨文件验证**：不能只看大纲，要对比伏笔总览+正文
2. **大纲内部一致性要检查**：概览表 vs 详细阶段标题 vs 章节内容
3. **新角色登场时间要确认**：任务body中的角色引入 vs 卷级概览中的正式加入时间
4. **任务规格预审核能节省大量时间**：在dispatch前发现问题，比写完后返工成本低得多

## 多轮审核发现的深层问题（第二轮）

第一轮修复后再次审核，发现以下深层问题：

### 6. 修复引入新问题
- 修复"玛拉重复说话"时将第一个"玛拉"改为"凯尔"，但凯尔在第081章才正式登场 → 第069章凯尔提前出现
- **教训**：修复一个问题时要检查修改是否与其他约束冲突

### 7. 角色时间线错乱
- 凯尔在第075章已出现在团队中（开玩笑被玛拉踢），但第081章才是"正式登场"
- **教训**：新角色的"登场"章之前不应有物理在场描写

### 8. 状态起始值矛盾
- 卷起始状态已描述污染疤痕"手腕到肩膀"，但第149章又描述"从手腕蔓延到肩膀" → 没有真正扩大
- **教训**：检查角色状态变化时，确保每次"扩大"都超出已有范围

### 9. 六维度引用章节号错误
- 六维度总结区引用的章节号与正文实际内容不符（如"第072-073章"实际在070-071章）
- **教训**：六维度标注必须与正文交叉验证

### 10. 已声明修复未生效
- 审核员声明"已将X修改为Y"，但文件中实际内容仍为原始的X
- **教训**：修复后必须用grep验证替换是否实际发生

## 多 agent 审核链（实战确认）

```
闪莉写完5章
  → 莉莉（v4-flash）审写作质量（字数/风格/大纲一致性）
  → 修改
  → 大莉M（mimo-v2.5-pro）审结构一致性（角色矛盾/编号冲突/标注遗漏）
  → 修改
  → 再审
  → 通过后继续下一批
```

两层审核不可省略：莉莉审"写得好不好"，大莉M审"设定对不对"。
