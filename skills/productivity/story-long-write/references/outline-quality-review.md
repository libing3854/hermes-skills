# 大纲质量审核工作流（P0-P3 优先级迭代）

> 实战总结于 2026-05-26，《我在深渊开事务所》第二卷大纲审核

---

## 流程概览

```
建纲 → 派大莉审核 → 按P0-P3修 → 派大莉再审 → 定稿
```

---

## 审核模板（delegate_task to 大莉）

```python
delegate_task(
    tasks=[{
        "goal": "请深度审核《{书名}》第{x}卷详细章级大纲",
        "context": (
            f"大纲文件路径：{path}/大纲_第{x}卷_详细章级大纲.md\n\n"
            "审核维度：1.整体结构 2.人物塑造 3.节奏把控 4.伏笔设计 5.主题表达\n"
            "请按P0-P3分级给出优化建议。"
        ),
        "model": {"model": "deepseek-v4-pro", "provider": "deepseek"},
        "toolsets": ["terminal", "file"]
    }],
)
```

---

## P0-P3 分级标准

| 优先级 | 含义 | 处理方式 |
|--------|------|---------|
| **P0（必须修）** | 前后矛盾、重复、逻辑漏洞 | 立即修复，不允许跳过 |
| **P1（强烈建议）** | 决战段偏短、配角弧线缺失、伏笔无推进 | 原则上必须修 |
| **P2（建议）** | 节奏偏慢、功能性角色、追踪缺失 | 建议修复 |
| **P3（锦上添花）** | 主题辩论、额外线索、收束压缩 | 有时间就修 |

---

## 修复流程

1. 按 P0→P1→P2→P3 顺序逐一修复
2. 每修复一条更新 todo 任务状态
3. 全部修完后，派大莉做 **二次审核**，确认修复到位
4. 二次审核通过后定稿

---

## 常见审核发现的问题（实战总结）

### P0 级

| 问题 | 描述 | 修复方案 |
|------|------|---------|
| 角色设定前后矛盾 | 如玛拉的"朔月潜质"在第x章说有，在第y章又说失去了 | 统一设定，选择其一并保持一致，在设定说明中标注清楚 |
| 同一内容重复出现 | 如市长来信在多个章节展示全文 | 只保留一次，其余改为引用或删除 |
| 时间线冲突 | 如"战后一周"和"一周后"在同一时间点重复使用 | 统一时间描述 |

### P1 级

| 问题 | 描述 | 修复方案 |
|------|------|---------|
| 决战段偏短 | 卷末高潮少于 7-8 章，三路战斗没有充分展开 | 扩充至 7-8 章，每路至少 1-2 章 |
| 关键配角在决战中缺席 | 铺垫了两卷的角色在最大事件中无贡献 | 给其独特的情报/技能贡献，不直接参战也可发挥作用 |
| 伏笔引入后无推进 | 某个伏笔在整卷中只有引入没有后续 | 卷末加一句状态更新（如克莱因战后升迁） |
| 能力成长与设定不一致 | 能力进化轨迹在章节间断裂 | 创建能力成长轨迹表，每卷一张 |

### P2 级

| 问题 | 描述 | 修复方案 |
|------|------|---------|
| 开篇节奏偏慢 | 前 3-4 章没有早期冲突，读者可能失去动力 | 加入早期小冲突（如被污染者袭击、低语教会探子追踪） |
| 配角色功能性化 | 某些角色沦为"递情报工具人" | 给其专属章节，展示内心矛盾或独立决策 |
| 反派缺少追踪 | 反派消失后团队没有尝试追踪，显得不积极 | 加入追踪失败场景，合理化"无能为力" |
| 连续高压缺呼吸 | 多章连续高压没有喘息空间 | 在中段插入一章日常/团队互动 |

### P3 级

| 问题 | 描述 | 修复方案 |
|------|------|---------|
| 反方缺少哲学论证 | 反派动机只用对话处理，没有形成主题辩论 | 在决战中展开"为什么保护这个腐烂的世界"的辩论 |
| 线索缺少卷末推进 | 重要线索在卷末没有新的推进 | 抓捕一个相关人物，获取下一级代号 |
| 卷末收束过长 | 战后恢复超过 10 章，稀释冲击力 | 压缩至 6-8 章 |
