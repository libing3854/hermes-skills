# 批次续写工作流（Batch Continuation Workflow）

> 当冰哥说"开始新的一批写作"时，按此流程执行。

## 流程概览

```
1. 确认当前进度 → 找到最新章节号
2. 定位大纲文件 → 找到对应卷的大纲
3. 映射章节号 → 大纲相对编号 ↔ 正文绝对编号
4. 读取前情 → 上一章结尾作为前情提要
5. 读取大纲 → 本批次要写的章节大纲
6. 生成任务body → 使用 writing-preset 模板
7. 创建看板任务 → hermes kanban create --assignee shanli
```

## 详细步骤

### Step 1：确认当前进度

```bash
# 找到最新章节
ls -1t /Users/libing/Desktop/临时文件-0001/脑洞文/正文/第*章*.md | head -5

# 统计最新章节字数
for f in $(ls -1t 正文/第*章*.md | head -5); do
  echo "$(basename $f): $(wc -m < "$f") 字符"
done
```

**输出**：最新章节号（如第217章）

### Step 2：定位大纲文件

大纲文件位置规则：
- 第一卷：`大纲_第一卷_优化版.md`
- 第二卷：`大纲_第二卷_详细章级大纲.md`
- 第三卷：`大纲存档/第三卷_完整详细大纲_终版_备份.md`
- 第四卷：`新第四卷_详细章节大纲_潮港青铜.md`

```bash
# 检查大纲文件
ls -la /Users/libing/Desktop/临时文件-0001/脑洞文/*卷*大纲* 2>/dev/null
ls -la /Users/libing/Desktop/临时文件-0001/脑洞文/大纲存档/*卷* 2>/dev/null
```

### Step 3：映射章节号

**关键问题**：大纲用相对编号（第001-082章），正文用绝对编号（第196-277章）

**映射方法**：
1. 找到大纲的"卷起始章节号"（通常在大纲开头或搜索"VOL.X"）
2. 计算偏移量：绝对编号 = 大纲相对编号 + 起始偏移

**示例**：
- 第四卷大纲从第001章开始
- 第四卷绝对起始 = 第196章（假设第三卷结束于第195章）
- 大纲第022章 = 正文第217章（196 + 22 - 1 = 217）
- 下一批大纲第023-027章 = 正文第218-222章

**验证方法**：
```bash
# 搜索大纲中的绝对章节号（如果有）
grep -n "第218\|第219\|第220" 大纲文件.md

# 或搜索卷起始说明
grep -n "VOL.4\|第四卷.*第" 大纲文件.md
```

### Step 4：读取前情

```bash
# 读取上一章结尾（最后50行）
tail -50 正文/第217章_共鸣.md
```

**提取要点**：
- 场景位置（如"泵机室"）
- 在场角色
- 关键对话/动作
- 情绪状态
- 悬念/钩子

### Step 5：读取大纲

```bash
# 搜索本批次章节的大纲位置
grep -n "^## 第023\|^## 第024\|^## 第025\|^## 第026\|^## 第027" 大纲文件.md

# 读取对应章节内容（使用 read_file 工具）
```

**每章提取**：
- 字数目标
- 场景
- 内容要点
- 情绪基调
- 伏笔
- 特殊要求（如克苏鲁氛围）

### Step 6：生成任务body

使用 `writing-preset` 模板1（长篇日更），填充以下内容：

```markdown
# 第四卷写作：第X批次（第XXX-YYY章）- 核心事件摘要

## 前情提要（第XXX章结尾）
[从Step 4提取]

## 本批次章节大纲
[从Step 5提取，每章一个子标题]

## 写作要求
### 字数硬约束
- 每章中文字数≥5000字，这是硬性要求！

### 写作风格（去AI味）
1. 段落以1-3句为主
2. 心理描写外化为动作
3. 对话标签≤30%
4. 禁用词扫描
5. 章尾用动作/场景收尾

### 角色名规范
[列出本批次涉及角色]

### 术语规范
[列出本卷相关术语]

### ⚠️ 重要：禁止两稿拼接！
[writing-guardrails 中的防拼接约束]

### ⚠️ 禁止使用的模板化短语
[writing-guardrails 中的反模板词典]

## 文件路径
- 正文目录：/Users/libing/Desktop/临时文件-0001/脑洞文/正文/
- 大纲文件：[路径]
- 上一章：[路径]

## 执行步骤
1. 读取上一章结尾
2. 读取大纲
3. 逐章写作，每章≥5000字
4. 字数验证（wc -m）
5. 禁用词扫描
6. 去AI味检查
7. 写入文件
8. 完成确认

## 审核流程
[标准审核流程]
```

### Step 7：创建看板任务

```bash
hermes kanban create "第四卷写作：第X批次（第XXX-YYY章）- 核心事件" \
  --assignee shanli \
  --max-runtime 2h \
  --max-retries 5 \
  --workspace dir:/Users/libing/Desktop/临时文件-0001/脑洞文 \
  --body "$(cat /tmp/kanban_body.md)"
```

## 常见陷阱

### 1. 大纲章节编号混淆
- **问题**：大纲用相对编号（第001章），正文用绝对编号（第217章）
- **解决**：先确认卷起始绝对编号，再计算偏移量

### 2. 前情提要不完整
- **问题**：只读了最后一句，遗漏了场景、角色、情绪
- **解决**：读取最后50行，提取所有关键要素

### 3. 任务body缺少关键约束
- **问题**：没有防拼接约束、反模板词典
- **解决**：使用 writing-preset 模板，嵌入 writing-guardrails 的约束

### 4. 字数目标未明确
- **问题**：大纲有字数目标但任务body没写
- **解决**：每章大纲的"字数目标"必须复制到任务body

### 5. 角色名规范遗漏
- **问题**：新角色（如萝莎）未列入角色名规范
- **解决**：读取大纲时提取所有出场角色，列入任务body
