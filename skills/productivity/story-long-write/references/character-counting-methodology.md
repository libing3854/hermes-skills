# 网文字数统计方法论

## 核心问题

不同统计方式对同一章节的字数结果差异巨大：

| 统计方式 | 公式 | 第088章实际结果 | 说明 |
|---------|------|----------------|------|
| `wc -m` | 所有非空白字符 | 5,484 | 包含markdown标题、英文、标点、数字 |
| `python3 len()` | 所有字符（含空白） | ~7,000+ | 包含空行、缩进、换行 |
| 纯中文字符 | `[\u4e00-\u9fff]` | 4,313 | 只计汉字，不含标点 |
| **中文+标点+数字** | `[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef0-9]` | **4,874** | **网文平台标准** |

## 网文平台字数标准

番茄小说等平台的字数统计通常采用 **"中文字符 + 中文标点 + 数字"** 标准：
- ✅ 计入：汉字、中文标点（，。！？、；：""''）、全角符号、数字
- ❌ 不计入：英文字符、半角标点、空行、缩进、markdown标记

## 精确统计脚本

```python
# 网文平台标准字数统计（推荐）
python3 -c "
import re, sys
content = open(sys.argv[1], encoding='utf-8').read()
# 去掉markdown标题行
lines = [l for l in content.split('\n') if not l.startswith('#')]
body = '\n'.join(lines)
# 中文+中文标点+数字
count = len(re.findall(r'[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef0-9]', body))
print(f'网文字数: {count}')
" "第088章_杰克的决定.md"
```

## 快速对比（bash一行版）

```bash
# wc -m（全字符，偏高）
wc -m < "第088章.md"

# 纯中文字符（偏低）
cat "第088章.md" | grep -oP '[\x{4e00}-\x{9fff}]' | wc -l

# 网文标准（推荐）
python3 -c "
import re; c=open('第088章.md').read()
print(len(re.findall(r'[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef0-9]', c)))
"
```

## 字数不足时的扩充方向

当统计发现字数不足5000字时（用网文标准统计），优先扩充方向：

1. **环境细节**：场景中的视觉/听觉/触觉描写（蒸汽、光线、气味）
2. **角色互动**：队友之间的简短对话或动作反应（1-2句即可）
3. **动作分解**：把一个动作拆成2-3个连续小动作
4. **感官线索**：角色的生理反应（心跳、呼吸、肌肉紧绷）
5. **世界观细节**：城市设施、社会规则、日常生活的碎片

**不要用以下方式凑字数：**
- ❌ 大段内心独白（AI味重）
- ❌ 重复已有信息
- ❌ 解释性旁白
- ❌ 无意义的环境描写堆砌

## ⚠️ 实战陷阱：wc -m 的虚假安全感

`wc -m` 会把 markdown 标题行、英文、空行中的不可见字符全部计入，导致数字偏高。实战中多次出现 `wc -m` 显示 5400+ 但网文标准统计只有 4800 的情况（2026-06-01 第087-092章验证）。

**快速检查用 wc -m 可以，但最终验证必须用网文标准脚本。** 看板任务中应要求闪莉"写完后用网文标准统计确认≥5000字"，而非仅 `wc -m`。
