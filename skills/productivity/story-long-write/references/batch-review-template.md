# 批量章节审核模板（大莉M深度审核版）

> 用于闪莉写完一批章节后，大莉M进行深度审核。经《我在深渊开事务所》第三卷第一批（第067-071章）实战验证有效。

## 调用方式

```python
delegate_dalim()  # 切换到大莉M
delegate_task(tasks=[{
    "goal": "深度审核《某小说》第X卷第一批章节（第YYY-ZZZ章）",
    "context": f"""..."""
}])
delegate_restore()  # 恢复默认模型
```

## 审核维度

### 五维评分法（标准版）

适用于常规批次审核：

### 1️⃣ 字数检查
- 每章目标字数（如5000-6000中文字符）
- 用 Python 精确统计中文字符：`sum(1 for c in content if '\u4e00' <= c <= '\u9fff')`
- 注意：文件总字符 ≠ 中文字符数，标点/空格/换行不计
- 逐章列出：章名 | 中文字符 | 达标/不足

### 2️⃣ 大纲一致性
- 核对各章核心事件是否与大纲一致
- 核对关键情节是否出现在对应章节
- 注意：大纲中的患者症状、场景细节、角色互动是否被简化/替换
- 偏差分级：完全吻合 / 轻微偏差 / 严重偏离

### 3️⃣ 标注元素处理
- 逐章追踪大纲标注元素（如【E-城市电台】【A-底层群像】【F-队友日常互动】【B-杰克童年回忆】等）
- 制成追踪表：

| 元素 | 067 | 068 | 069 | 070 | 071 | 完成状态 |
|------|-----|-----|-----|-----|-----|---------|
| 【E-城市电台】 | ✅/❌ | ... | ... | ... | ... | N/M |

### 4️⃣ 角色连贯性
- 检查角色性格、说话方式、行为逻辑是否与前文一致
- 角色名规范检查（去姓/全名规则）
- 新角色命名风格检查

### 5️⃣ 写作风格
- 短段落检查（段落以1-3句为主）
- 动作展示 vs 心理陈述比例
- 对话自然度（是否有说教/解释感）
- 是否升华收尾（错误信号：章节末的总结式感慨）
- 去AI味程度（禁用词密度）

### 八维评分法（深度版）

适用于跨卷/重大转折批次审核，或五维审核发现角色/术语问题时升级使用：

| 维度 | 检查内容 |
|------|---------|
| 1️⃣ 内容一致性 | 章节内容是否符合大纲要求，核心事件是否覆盖 |
| 2️⃣ 人物设定 | 角色行为、对话是否符合人设，角色名是否正确 |
| 3️⃣ 剧情逻辑 | 情节推进是否合理，因果链是否完整 |
| 4️⃣ 能力设定 | 主角能力（污染视觉/时间突破等）使用是否正确 |
| 5️⃣ 伏笔铺设 | 机械神、三扇门等伏笔是否到位 |
| 6️⃣ 网文风格 | 去姓/短段/动作展示/不升华 |
| 7️⃣ 字数 | 每章是否达到5000-6000字 |
| 8️⃣ 术语一致性 | 黄金结社/金齿轮网络/齿轮守护者社团等术语是否统一 |

**升级触发条件**：
- 五维审核发现角色名错误或世界观不一致 → 升级为八维
- 跨卷审核（如第三卷第八批） → 直接使用八维
- 用户要求"深度审核" → 使用八维

**八维审核输出格式**：直接输出各维度逐章评审表 + 问题列表（按严重程度排序）+ 通过/不通过结论。不需要五维的综合评价卡。

## ⚠️ 常见审核发现（实战总结）

### 角色名/术语不一致（批次级别高频问题）
- **症状**：子代理写出来的章节使用了错误角色名（如用"林渊"代替"杰克"）或不存在的角色（如"苏晚晴""赵铁柱"）
- **根因**：子代理每次启动是全新会话，如果没有在 context 中明确列出角色规范，会自行编造角色名
- **术语缩写**：「齿轮守护者社」应为「齿轮守护者社团」，「下教会」应为「低语教会」
- **修复方法**：用 delegate_task 派遣 targeted fix 任务，逐章搜索替换
- **预防**：任务 body 中必须包含完整的角色名规范表（去姓/全名规则）和术语对照表

### 字数问题
- 第069章型：信息密度过高但场景化不足，大量信息以对话/报告方式直接输出
- 第071章型：关键场景被压缩，悬疑钩子未展开，团队讨论环节缺失
- **修复方向**：补充场景描写、角色互动、悬疑细节，而不是注水（增加环境描写/凑句子）

### 批量字数崩溃（批次级别问题）
- **单章不达标 ≠ 批次崩溃**：6/7章同时严重不足（2000-2900中文字符 vs 目标5000+）是批次级系统性失败
- 第087-092章批次总完成度仅52.9%（18,498字 vs 目标35,000字）
- **检查方法**：不仅看各章是否达标，还要计算批次总字数/目标总字数比例
- **阈值**：批次总完成度 < 70% → 标记为 P0 致命问题，暂停后续流程
- **修复方向**：不是逐章补字数，而是评估是否整个批次的剧情规划需要重新调整（字数不足往往是剧情量不足的体现）

### 大纲偏差模式
- **患者症状替换**：大纲中的视觉冲击力强的情节（如古神语写满墙）被替换为较弱版本（水缸倒影微笑）
- **医生角色缺位**：大纲中医生应在场的场景被其他角色替代——需确认是合理改写还是疏忽
- **标注元素弱化**：大纲标注的底层群像、城市电台等结构性元素被压缩或遗漏

### 🔴 P0 新增：整段剧情弧跳过（批次级别大纲偏离）
- **症状**：批次内章节完全跳过了大纲中规划的整段剧情弧（如第三卷第四批跳过「天空之城·中点大转折」，约28章内容直接跳到选举日决战）
- **与「大纲偏差」的区别**：
  - 大纲偏差 = 写了相同位置但内容有出入（如患者症状替换）
  - **剧情弧跳过 = 这个位置的内容根本不是大纲那一段**（章节标题、核心事件、情绪弧线全部不同）
- **检查方法**：读取大纲该范围的「核心事件」列 → 交叉对比实际章节的「核心事件」 → 如果完全不同，确认是否跳过
- **实战案例**：大纲规划第089章「维拉的发现→天空之城文件」→ 实际写为「杰克的过去（童年回忆）」；第092章大纲「天空之城伊甸初见」→ 实际写为「决战前夜·封印完成」
- **影响评估**：跳过整段剧情弧意味着：1) 该段落的设定揭示和世界观展开丢失；2) 后续章节失去结构支撑（如天空之城不出现，则普罗米修斯计划、凯瑟琳天空之城高光、艾琳娜抉择全部无法展开）；3) 可能导致全书结构从95章压缩到约70章，影响整体规划
- **修复方向（两种方案）**：
  - **方案A（推荐）**：重写批次，恢复大纲剧情弧。已写内容作为素材保存复用
  - **方案B（压缩）**：接受偏离，扩充字数+补充标注元素，但需确认全书结构是否还支撑得起来

### Deus Ex Machina 检测
- **症状**：重要角色突然出现解决问题，前文无铺垫（如会长在第090章突然出现，带来第三枚铜牌和封印方案）
- **检测方法**：检查每个关键转折点是否有「前置铺垫」——角色出现前是否存在伏笔/线索/预兆？如果首次出现就解决了核心问题，标记为 Deus Ex Machina
- **P0级**：如果 Deus Ex Machina 角色承担的剧情功能原本由骨架级设定（如天空之城）提供，则必须修复（通过铺垫或恢复原大纲剧情）

### 角色名规范
- 第067章常见：电台播报/新闻报道中使用全名（如「卡尔·斯特恩」）——可接受为正式格式，但后续应在正文中去姓
- 新角色（如精神病院霍华德医生）命名风格需与全书一致

### 写作风格风险
- **「简报体」风险**：大量信息同时输出（六边形分析、23起死亡、声纹匹配87%），缺乏场景化
- **段落密度失控**：重新设计版可能比修正版段落更短，但场景信息量也减少了
