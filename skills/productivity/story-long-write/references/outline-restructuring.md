# 大纲跨卷重构工作流

> 当用户要求移动卷的位置（如"第四卷改成第八卷"）、合并卷、或重新排列卷序时使用。

---

## 触发场景

1. **卷位置调整**：用户在写了几卷后，决定把某卷移到后面（如原第四卷→最终卷第八卷）
2. **卷合并/拆分**：两个大纲合并成一卷，或一卷拆成两卷
3. **卷序重排**：调整卷的先后顺序

---

## 工作流程

### Step 1：确认修改范围

在动手前，必须和用户确认：
- 哪些卷需要调整？
- 调整后的新卷序是什么？
- 章节编号是硬编码还是用相对位置？

### Step 2：修改卷头部信息

每个被调整的卷，需要更新：
- **卷名/标题**：`第四卷` → `第八卷`
- **位置说明**：明确衔接哪一卷
- **起始状态**：根据前一卷的结束状态更新
- **情绪弧线表格**：章节编号或相对位置
- **核心设定回顾**：根据新位置更新角色状态

### Step 3：更新章节编号

**关键原则：如果前几卷还没写完，不要硬编码绝对章节编号。**

用相对位置标注：
- 情绪弧线：`前1/7`、`中间`、`最后1/7`
- 情节点内：`第一部分`、`第二部分`、`第三部分`
- 鉴定能力轨迹：`开头`、`前1/4`、`中间`、`结尾`

### Step 4：检查跨卷影响

被调整的卷中可能引用了其他卷的事件。需要检查并更新：

| 检查项 | 说明 |
|--------|------|
| 角色状态引用 | "第三卷遗留"、"前作影响"等标签需要更新 |
| 章节编号引用 | 正文中的"第X章"需要更新 |
| 情节衔接 | 卷末钩子需要指向新的下一卷 |

### Step 5：更新被调整卷的大纲

在被调整卷的大纲中加入对前面卷的后续影响标签，如：
- `【第三卷后续影响】`
- `【机械神觉醒延续】`
- `【塞拉斯深渊关联】`
- `【会长远程指导】`

---

## 文件修改清单

当卷位置调整时，需要修改的文件：

```
被调整卷的大纲文件：
├── 头部信息（卷名、位置、起始状态）
├── 情绪弧线表格（章节编号或相对位置）
├── 各情节点（章节编号、引用标签）
├── 核心设定回顾（角色状态）
└── 鉴定能力成长轨迹（章节编号）
```

---

## 常见错误

1. **硬编码章节编号**：前几卷还没写完就定死编号 → 用相对位置
2. **忘记更新引用标签**：`【第三卷遗留】` 没改成正确的卷号
3. **角色状态不一致**：被调整卷中的角色状态与新位置不符
4. **情节点编号混乱**：多个情节点用相同编号

## 冰哥项目案例

### 案例：原第四卷《终局》→ 第八卷

**修改内容：**
1. 标题：`第四卷：终局` → `第八卷：终局`
2. 位置：`原第四卷` → `最终卷，接在《同源之战》（第七卷）之后`
3. 起始状态：`卷三结束后` → `第七卷《同源之战》结束后，共济会三派初步停战，封印倒计时六十天`
4. 章节编号：`第124-178章` → 相对位置（前1/7、中间、最后1/7）
5. 封印时间：`两年内` → `六十天内`
6. 角色状态：删除已故角色（乔治在第三卷牺牲）
7. 能力描述：更新为包含场域鉴定和历史共鸣
