# 新小说项目目录结构标准

适用于番茄小说新书项目。来源：冰哥确认的"番茄新书_请神系统文"项目结构。

## 根目录结构（2026-07-03 更新）

```
番茄新书_XXX/
├── 00_项目说明/      # 项目规则、写作标准、目录说明
├── 01_正文/          # 确认进入小说正文的章节（只有定稿才放这里）
├── 02_大纲/          # 灵感大纲（故事结构和章节规划）
├── 03_执行大纲/      # AI写作施工图（每章具体约束）
│   ├── 00_总资料/    # 跨卷通用规则
│   └── 01_第一卷_XXX/ # 每卷单独扩写资料
├── 04_设定/          # 确认采用的世界观、系统、能力
├── 05_素材库/        # 参考资料（道教文化、民俗、市场调研）
├── 06_角色卡/        # 角色卡标准、模板、已确认人物的大纲
├── 07_未定稿/        # 没确定是否采用的想法
├── 08_临时正文/      # AI生成的正文草稿（按模型分目录）
│   ├── mimo写/       # MiMo v2.5 输出
│   ├── 闪莉写/       # 闪莉 LongCat 输出
│   └── agnes写/      # agnes-2.0-flash 输出
├── 09_临时文件/      # 检查脚本、评估报告、修正提示
└── 10_废稿备份/      # 被替换/废弃但可能回看的内容
```

## 与"我在深渊事务所"的关系

"我在深渊事务所"使用旧结构（weinMac/临时文件-0001），保持不变。新项目使用上述标准结构。
