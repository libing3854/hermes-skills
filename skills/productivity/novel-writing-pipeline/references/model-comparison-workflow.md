# 模型对比写作工作流

## 概述
当需要对比不同AI模型的写作能力时，安排多个模型写相同内容，用脚本量化对比。

## 流程

### 1. 准备阶段
- 创建独立输出目录：`08_临时正文/模型A写/`、`08_临时正文/模型B写/`
- 准备统一的写作要求（字数、禁用词、大纲、角色设定等）
- 准备质量检查脚本

### 2. 派发任务
- **闪莉/LongCat**：用kanban任务派发
  ```bash
  hermes kanban create --assignee shanli --workspace "dir:输出目录" --body "写作要求" "任务标题"
  ```
- **MiMo v2.5**：用`hermes -p mimo-v25 chat -q`执行
  ```bash
  hermes -p mimo-v25 chat -q '写作要求' -Q --max-turns 1 > 输出文件.md
  ```
- **其他模型**：创建对应profile后用同样方式

### 3. 等待完成
- kanban任务：`hermes kanban list | grep 任务标题`
- profile任务：后台进程完成后自动通知

### 4. 运行检查脚本
```bash
python3 09_临时文件/章节质量检查脚本.py
```

### 5. 对比报告
检查脚本输出对比表：
- 字数统计
- 禁用词检查
- 高频词检查
- 综合评分

## 注意事项
- 每个模型的输出目录必须独立，避免互相踩踏
- 写作要求必须完全一致，才能公平对比
- 检查脚本放在09_临时文件/目录
- 对比结果保存供后续参考
