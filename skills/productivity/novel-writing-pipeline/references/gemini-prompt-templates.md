# Gemini 网页版提示词模板

## 使用方法
1. 打开 https://gemini.google.com
2. 选择模型：Gemini 3.5 Flash（深度思考）
3. 复制提示词，粘贴到输入框
4. 把章节内容粘贴到指定位置
5. 等待生成，复制输出

---

## 写作提示词（单章）

```
你是一个专业的中文网络小说作家。请根据以下大纲和前文风格，写出完整的章节。

【前一章结尾参考】
（粘贴前一章最后500-1000字）

【本章大纲】
第{章节号}章：{章节标题}
（粘贴大纲中该章节的内容要点）

【写作风格要求】
1. 4500-6000纯汉字（不含标点符号）
2. 禁用词（0次）：仿佛、深吸一口气、不由得
3. "像"比喻每章≤10次，"如同"≤3次，"某种"≤3次，"一种"≤5次
4. 对话自然，不要说教感
5. 段落不要太长，保持节奏
6. 直接输出完整章节markdown，以 # 第{章节号}章：{章节标题} 开头

请直接输出完整章节内容。
```

## 审核提示词（8维度）

```
请审核以下小说章节，从8个维度评估：

1. 剧情连贯性（时间线、角色状态、事件因果）
2. 剧情bug（矛盾、不合理、前后不一致）
3. 大纲匹配度（主要情节点是否覆盖）
4. 角色弧线（主要角色发展是否合理）
5. 伏笔埋设与回收
6. 对话质量（角色台词是否符合性格、是否自然流畅）
7. AI味检测（高频词/句式/模板化）
8. 字数统计（每章纯汉字数是否达标4500-6000）

【章节内容】
（粘贴章节全文）

【大纲参考】
（粘贴对应大纲内容）

请逐章输出审核报告，每个问题标注严重度（P0/P1/P2）。
```

## 修改提示词

### 清除禁用词

```
以下章节包含禁用词，请全部替换为非禁用表达。

【禁用词列表】
- 仿佛 → 替换为：像是、如同、如、似、恍若、宛若
- 深吸一口气 → 替换为：深呼吸、吸了口气、屏住呼吸
- 不由得 → 替换为：忍不住、不禁、情不自禁（但"不禁"也要少用）

【当前章节内容】
（粘贴章节全文）

【要求】
1. 找出所有禁用词并替换
2. 保持原文风格和意思不变
3. 输出完整的修改后章节

请直接输出修改后的完整章节内容。
```

### 削减"像"系词

```
以下章节"像"字使用过多（超过10次），请削减到10次以内。

【当前章节内容】
（粘贴章节全文）

【削减方法】
1. 保留最精彩的3-5个"像"比喻
2. 其余"像"直接删除或改写
3. 例："像心跳" → "心跳"
4. 例："像是在说" → "在说"
5. 例："像一座城市" → "一座城市"

【要求】
1. 保留核心比喻，删除冗余
2. 保持原文风格和意思不变
3. 输出完整的修改后章节
4. 标注修改了几处

请直接输出修改后的完整章节内容。
```

### 扩写字数不足

```
以下章节字数不足（低于4500字），需要扩写。

【当前章节内容】
（粘贴章节全文）

【扩写要求】
1. 保持原有情节和对话不变
2. 增加场景描写、人物内心活动、动作细节
3. 不要改变故事走向
4. 不要添加新情节
5. 扩写后总字数目标：4500-5500纯汉字
6. 禁用词（0次）：仿佛、深吸一口气、不由得
7. 直接输出完整的扩写后章节markdown

请直接输出扩写后的完整章节内容。
```

4. 精简后总字数目标：5000-5500纯汉字
5. 直接输出完整的精简后章节markdown

请直接输出精简后的完整章节内容。
