# GitHub Trending 项目推荐 — 工作流

## 页面描述

GitHub Trending 页面（https://github.com/trending）展示了 GitHub 社区当天或指定时间段内最受关注的开源项目。页面顶部有筛选器，可以按语言、日期范围（今天、本周、本月）和口语语言进行过滤。项目列表以卡片形式展示，包含项目名称、描述、主要编程语言、星标数和今日新增星标数。

## 任务步骤

### 1. 导航至 GitHub Trending 页面
访问 URL：https://github.com/trending

### 2. 设置筛选器
确保页面筛选器设置为：
- 时间范围：**今天**
- 编程语言：**任何**
- 口语语言：**任何**

### 3. 提取项目列表
提取页面上的完整项目列表。

### 4. 分析提取内容
识别所有 trending 项目，每个项目条目包含：
- 项目名称（格式为 "用户名 / 仓库名"）
- 描述
- 主要编程语言
- 星标数据

### 5. 根据用户偏好匹配筛选
根据 **用户偏好关键词** 中提供的技术偏好，对列表中的项目进行匹配筛选。

**常见关键词类别：**
| 类别 | 示例关键词 |
|------|-----------|
| AI 工具 | LLM、ChatGPT、Claude、Agent、RAG、Fine-tuning |
| 开发者效率 | CLI、Terminal、DevOps、Automation、Testing |
| 多媒体处理 | Video、Image、Audio、3D、Rendering |
| 安全隐私 | Security、Encryption、Privacy、Auth |
| 前端/UI | React、Vue、CSS、Animation、Design System |
| 数据/后端 | Database、API、Microservice、Streaming |

### 6. 选择最相关的前 N 个项目
从匹配的项目中，选择最相关的前 N 个项目（N 由 **目标项目数量** 决定）。

### 7. 生成推荐报告
报告应包含：
- 用户偏好分析总结
- 匹配成功的项目列表（每个项目含名称、描述、匹配原因）

## 关键考虑

- 提取页面内容后，需要解析 HTML 文本来识别项目信息
- 匹配筛选时，优先考虑项目描述和名称中包含关键词的项目
- 如果当天匹配的项目数量不足，可以将时间范围调整为 **本周** 以获取更多候选项目

## 特殊场景

| 场景 | 处理方式 |
|------|---------|
| Trending 页面无法访问 | 使用 web_search 搜索 "GitHub trending today [年份] [用户偏好关键词]" |
| 页面内容提取失败 | 重新加载页面或等待几秒后重试 |
| 项目描述模糊 | 根据仓库名称和编程语言合理推断 |
| 匹配数量不足 | 将时间范围扩大到"本周" |
