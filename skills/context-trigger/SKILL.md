# 上下文标注指南（Context Trigger）

在细纲和看板任务body中标注本章需要的上下文，确保写作时加载正确的设定文件。

**定位：** 本技能提供标注格式规范，实际上下文加载流程由 story-long-write 的 Phase 4 步骤2 驱动。

## 什么时候标注

1. **创建细纲时**：在每个细纲文件末尾添加"上下文标注"段落
2. **创建看板任务时**：在任务body中添加"本章上下文"段落

## 标注格式：细纲文件

在 `大纲/细纲_第XXX章.md` 末尾添加：

```markdown
### 上下文标注
- 角色：[列出本章出场角色]
- 地点：[列出本章场景地点]
- 伏笔：[列出本章需回收/推进的伏笔，标明伏笔编号或描述]
- 设定：[列出本章涉及的特殊设定，如力量体系规则、组织架构等]
```

示例：

```markdown
### 上下文标注
- 角色：杰克、玛拉
- 地点：下水道、旧城区
- 伏笔：三体符号吊坠（第008章埋设，本章推进）、污染源位置（本章揭示）
- 设定：古神侵蚀的三个阶段、朔月净化机制
```

## 标注格式：看板任务body

在看板写作任务的body中添加：

```
### 本章上下文
本章涉及：
- 角色：杰克（状态：左臂疤痕疼痛加剧）、玛拉（状态：新觉醒感知能力）
- 地点：下水道（设定：潮湿、黑暗、有污染源）
- 伏笔：三体符号吊坠（第008章埋设）、污染源位置
- 设定：古神侵蚀三阶段、朔月净化机制

请读取以上角色的设定文件和相关伏笔文件。
```

## 标注与加载的关系

标注完成后，写作时按 story-long-write 的 Phase 4 步骤2 的优先级加载文件：

| 优先级 | 文件 | 来源 |
|--------|------|------|
| 最高 | 本章细纲 | 标注中的信息帮助确认加载哪些 |
| 高 | 上一章正文 | 始终加载 |
| 高 | 相关角色设定 | 标注中的"角色"列表 |
| 中 | 追踪/伏笔.md | 标注中的"伏笔"列表帮助定位 |
| 中 | 追踪/角色状态.md | 标注中的"角色"列表 |
| 中 | 相关世界观设定 | 标注中的"设定"列表 |
| 低 | 对标书参考 | 按需 |

完整加载流程见 story-long-write 的 Phase 4 步骤2。

## 与其他技能的关系

| 技能 | 关系 |
|------|------|
| **story-long-write** | 主流程引擎，上下文加载流程在 Phase 4 步骤2 |
| writing-preset | 看板任务body模板中包含本技能的上下文标注 |
| character-dialogue-template | 角色设定文件随标注中的"角色"列表一起加载 |

## 注意事项

1. 标注是手动操作——创建细纲时必须手动添加
2. 每章至少标注：角色、地点、伏笔（3项必填）
3. "设定"字段可选，只在涉及特殊规则时填写
4. 加载优先级和加载流程引用 story-long-write，这里不重复
