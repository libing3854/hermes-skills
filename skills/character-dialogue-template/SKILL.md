# 角色对话模板（Character Dialogue Template）

每个角色文件中必须包含"示范对话"段落，用于锁定角色说话风格。

**定位：** 本技能定义角色文件中"示范对话"段落的格式，其他段落格式由 story-long-write 定义。

## 角色文件标准格式

每个角色文件（`设定/角色/角色名.md`）应包含以下段落。其中"示范对话"是本技能的核心贡献：

```markdown
# 角色名

## 基本信息
- 年龄：
- 身份：
- 外貌：（关键特征，如疤痕位置、义肢等）

## 性格特点
- 核心特质：（2-3个关键词）
- 说话风格：（一句话概括）

## 示范对话（必填，至少3段）

### 场景1：[具体场景名]
[角色名]："..."
（动作/表情）

### 场景2：[具体场景名]
[角色名]："..."
（动作/表情）

### 场景3：[具体场景名]
[角色名]："..."
（动作/表情）

## 语言特征
- 口头禅：
- 用词偏好：
- 禁止的说话方式：（不会说的词/不会用的句式）
```

## 示范对话编写技巧

### 1. 场景不固定，根据角色类型选择

不同角色的典型场景不同，不要硬套"日常/情绪激动/战斗"：

| 角色类型 | 推荐场景 |
|----------|----------|
| 战斗型 | 接委托、发现线索、战斗指挥 |
| 技术型 | 分析数据、解释技术、紧急修复 |
| 情报型 | 获取信息、审讯、社交场合 |
| 领导型 | 下达命令、鼓舞士气、艰难决策 |
| 日常型 | 闲聊、安慰他人、独处时 |

**最低要求：至少3段，覆盖该角色最常见的说话场景。**

### 2. 具体胜于抽象

❌ 错误示范：
```
[角色名]说话很直接。
```

✅ 正确示范：
```
[角色名]："说重点。我没时间听你绕弯子。"
（他看了一眼手表，眉头微皱）
```

### 3. 展示情绪变化

```
## 平静时
[角色名]："这件事，我们可以慢慢谈。"

## 愤怒时
[角色名]："够了。"（他猛地站起来，椅子向后滑出半米）
"你知不知道你在说什么？"

## 悲伤时
[角色名]："...我知道。"（她转过身去，肩膀微微颤动）
```

### 4. 锁定口头禅和用词

```markdown
## 语言特征
- 口头禅："说重点"、"行了行了"
- 用词偏好：短句，不用"您"，偶尔夹杂方言
- 禁止的说话方式：不会说"我觉得或许"、"可能大概"
```

## 角色属性速查表（看板任务专用）

在看板任务body中添加角色属性速查表，防止角色特征混淆：

```
### 角色属性速查
杰克：右脸颊污染疤痕、朔月潜质、直率战斗型 | 
玛拉：右腿义肢、技术型、差分机专家 | 
凯瑟琳：前警察、警觉分析型 | 
凯尔：过目不忘+模式识别、情报型
```

## 在看板任务中的应用

在写作任务body中添加：

```
### 角色对话规范
写作时请参考以下角色的示范对话：

**杰克**（`设定/角色/杰克.md`）：
- 说话风格：短句、直接、偶尔夹杂军事术语
- 口头禅："说重点"
- 禁止：不会说长篇大论、不会用敬语

**玛拉**（`设定/角色/玛拉.md`）：
- 说话风格：直率、带刺、但关心队友时会柔软
- 口头禅："别废话"
- 禁止：不会说甜言蜜语、不会主动道歉
```

## 与其他技能的关系

| 技能 | 关系 |
|------|------|
| **story-long-write** | 主流程引擎，角色文件的其他段落格式由该技能定义 |
| writing-preset | 看板任务body模板中包含本技能的角色对话规范 |
| writing-guardrails | 角色一致性检查参考本技能的示范对话 |

## 注意事项

1. 示范对话必须有**具体台词**，不能只写"说话很直接"
2. 至少3段，场景由角色类型决定，不硬套固定场景
3. 角色性格变化后要更新示范对话
4. 角色文件的其他段落格式与 story-long-write 一致
