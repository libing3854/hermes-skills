# 写作护栏（Writing Guardrails）

写完章节后的质量自查清单。嵌入看板任务body或审核流程中使用。

**定位：** 本技能提供自查清单格式，实际写作流程和去AI味规则由 story-long-write 驱动。

## 清单1：每章写完后自查

写完每章正文后，逐项检查：

### 风格检查
- [ ] 段落以1-3句为主，有长短交错（不写4-6句的均匀段落）
- [ ] 心理描写外化为动作（"手在抖"代替"他很紧张"）
- [ ] 对话标签使用频率 ≤30%（用动作引出对话）
- [ ] 章尾用动作/场景收尾，不用总结式感慨（"他知道...""这一刻..."）

### 禁用词检查
- [ ] 扫描禁用词：深吸一口气、眼中闪过/闪过一丝、嘴角勾起一抹、仿佛/犹如/宛若、不禁
- [ ] 扫描"那种"填充词（单章≤2次，超过则删"那种"直接说名词）
- [ ] 扫描"不是X，是Y"句式（单章≤10次，超过则改为肯定句或合并）
- [ ] 完整禁用词表见 story-deslop 的 `references/banned-words.md`

### AI高频词数量阈值（2026-06-09 实战验证）
- [ ] "仿佛" **0次/章**（禁用词，必须全部替换。替换策略：用多种近义词避免单调 → 像是/如同/好似/宛如/活像/仿佛→直接删。不要同一章内全部换成同一个词。示例：行7用"像是"，行9用"如同"，行75用"宛如"）
- [ ] "深吸一口气" **0次/章**（禁用词）
- [ ] "不由得" **0次/章**（禁用词）
- [ ] "像"字比喻 ≤10次/章（超过则削减，保留最精准的1-2个，其余改直接描写。⚠️ 网文平台读者对"像"敏感，15次已偏高，实战验证10次为安全线）
- [ ] "如同" ≤3次/章（⚠️ AI常将"像"替换为"如同"来规避≤15限制，但"如同"过度使用同样产生AI味。第282章实战：10次"如同"+7处"如——"断句，需削减）
- [ ] "如——"断句 ≤1次/章（AI将"像——"替换为"如——"，结构模式未变。保留风格化最强的1-2处，其余改为完整句式）
- [ ] "某种" ≤1次/章（超过则替换为具体描述，如"某种意志"→"海底的意志"）
- [ ] "一种" ≤3次/章（超过则替换为"一丝/一股/一阵/一份/某种"等近义词）
- [ ] "微微" ≤3次/章（超过则替换为"轻/略/稍"）
- [ ] "像在" ≤3次/章（句式模式化，超过则换用直接动词）
- [ ] "那种" ≤2次/章（AI模糊指示词，超过则删"那种"直接说名词。实战：单章可达7次）
- [ ] "不是X，是Y" ≤10次/章（AI最高频句式，超过则改写为肯定句。实战：单章可达21次）
- [ ] "16.9赫兹"类核心意象 ≤3次/章（适当重复强化记忆，超过5次产生疲劳感）
- [ ] "他停了一下" ≤2次/章（超过则替换为"顿了顿""沉默了片刻"等变体）
- [ ] 禁止跨段重复（同一段落/句式在章内出现两次 → 删除其一）

### 模板化短语黑名单
- [ ] "帮帮我" + "赫兹" 结尾模式
- [ ] "在三百公里外的东南方向"
- [ ] "它在播放它的音乐"
- [ ] "像心跳。像呼吸。"
- [ ] "不是疼痛。是温热/发热。"
- [ ] "嘴角微微上扬/上翘"
- [ ] "某种活着的东西"
- [ ] "像某种古老的。活着的。等待着的。东西。"

### 结尾检查（最易反弹的AI痕迹）
- [ ] 章尾是否为动作/场景收尾？（✅ "杰克跳了下去"）
- [ ] 章尾是否为总结式感慨？（❌ "他知道……""这一刻……""像承诺。像回家的路。"）
- [ ] 连续3章结尾是否结构雷同？（如都用"16.9赫兹。人类的频率。"收尾 → 必须改）

### 角色一致性检查
- [ ] 本章出场角色的说话风格是否符合 `设定/角色/角色名.md` 中的示范对话？
- [ ] 角色称呼是否统一？（去姓/全名是否与规范一致）
- [ ] 角色属性是否正确？（疤痕位置、义肢、年龄等）

## 清单2：每5章阶段性检查

每写完5章（或一批任务完成后），做以下检查：

### 连贯性检查
- [ ] 角色状态是否与 `追踪/角色状态.md` 一致？
- [ ] 伏笔推进是否与 `追踪/伏笔.md` 一致？
- [ ] 时间线是否与 `追踪/时间线.md` 一致？
- [ ] 章节编号是否连续、无跳号/重号？

### 风格漂移检查
- [ ] 最近5章的段落密度是否一致？（对比第1章和第5章）
- [ ] 对话比例是否稳定？
- [ ] 是否出现新的模板化结尾？（跨章重复的句式）

### 字数检查（⚠️ 必须用纯中文字计数）
- [ ] 每章是否达到目标字数范围？（常见：4500-5500短章 / 5000-6000标准 / 6000-8000长章，以用户指定为准）
- [ ] **计数标准：纯汉字（Unicode CJK范围），排除标点、空格、换行**
  ```python
  import re
  with open(file, encoding='utf-8') as f:
      text = f.read()
  hanzi_count = len(re.findall(r'[\u4e00-\u9fff]', text))
  ```
  ❌ 不要用 `wc -m`（算所有字符含标点空格，数字偏高30-40%）
  ❌ 不要用 `wc -w`（按空格分词，中文不准）
- [ ] 是否有章节严重超标（>6000中文字，可能需要拆分）？

## 使用方法

### 方法1：嵌入看板任务body

在写作任务body的"品质要求"段落中加入：

```
### 品质要求
写完每章后自查：
- [ ] 段落1-3句为主，有长短交错
- [ ] 心理描写外化为动作
- [ ] 对话标签≤30%
- [ ] 禁用词扫描（深吸一口气/眼中闪过/嘴角勾起/仿佛/犹如/宛若/不禁）
- [ ] 章尾动作收尾，无总结感慨
```

### 方法2：审核时使用

审核一批章节时，按清单1逐章检查，按清单2做阶段性检查。

## 审核报告交叉验证

当收到审核报告（尤其是多份报告结论不一致时），**必须独立验证底层数据后再采信结论**。

### ⚠️ 常见陷阱：审核报告数据失实

**实战教训（2026-06-11）：** 两份审核报告对同一批章节的字数统计出现严重分歧：
- Report A：第249章 5376字 ✅
- Report B：第249章 8421字 ❌（虚高57%）
- 实际验证：5376字（Report A 正确）

Report B 基于错误数据提出了"第249章需要分章"的建议 → 实际5376字完全在正常范围内，建议无效。

### 验证流程

```
1. 读取审核报告中的关键数据（字数、词频、评分）
2. 用 Python 独立验证（见下方脚本）
3. 对比报告数据与实际数据
4. 如果偏差 >10%，该报告的结论不可信
5. 委托第二审核员（莉莉）交叉评分
```

### 独立验证脚本

```python
import re, os

def validate_chapter(filepath):
    with open(filepath, encoding='utf-8') as f:
        text = f.read()
    chinese = len(re.findall(r'[\u4e00-\u9fff]', text))
    # 关键词统计
    keywords = {
        '像': len(re.findall(r'像', text)),
        '某种': len(re.findall(r'某种', text)),
        '微微': len(re.findall(r'微微', text)),
        '缓缓': len(re.findall(r'缓缓', text)),
        '仿佛': len(re.findall(r'仿佛', text)),
        '深吸一口气': len(re.findall(r'深吸一口气', text)),
    }
    return {'字数': chinese, **keywords}

# 批量验证
dir_path = '/Users/libing/Desktop/临时文件-0001/脑洞文/正文/'
for ch in range(245, 256):
    files = [f for f in os.listdir(dir_path) if f.startswith(f'第{ch}章_') and f.endswith('.md')]
    if files:
        result = validate_chapter(os.path.join(dir_path, files[0]))
        print(f'第{ch}章: {result}')
```

### 评分标准

| 报告质量 | 评分范围 | 特征 |
|----------|---------|------|
| 优秀 | 85-100 | 数据准确、覆盖全面、建议可执行 |
| 良好 | 70-84 | 数据基本准确、有遗漏但核心问题抓住 |
| 一般 | 50-69 | 数据有偏差、建议较宏观 |
| 不可靠 | <50 | 数据严重失实、结论不可信 |

### 关键原则

- **数据是审核报告的基石** — 字数统计、词频统计必须可复现
- **两份报告不一致时，以实际验证数据为准** — 不盲从任何一份
- **交叉审核用不同模型** — 避免同一模型的系统性偏差
- **文学分析可以参考，但技术数据必须独立验证**

详细流程见 `references/audit-report-cross-review.md`。

## 审核优先级规则（冰哥确认 2026-06-26）

审核章节时按以下优先级排序，高优先级问题必须先修：

| 优先级 | 检查项 | 处理方式 |
|--------|--------|----------|
| 🔴 P1 | 字数不达标（<4500字） | 必须补字数 |
| 🟠 P2 | 跨章重复（大段相同内容） | 必须重写 |
| 🟡 P3 | 一致性问题（角色/世界观/术语） | 必须修复 |
| 🟢 P4 | AI味（禁用词/高频词/模板化） | 放着继续写 |

### 断路器规则

- 每章最多修改**2轮**
- 如果第2轮修改后只剩AI味问题（P4）→ **跳过，继续写新章**
- 不要因为AI味问题停下来问冰哥，直接推进

### 审核流程

```
写完一批(2章) → 莉莉审核
  ↓
按P1→P2→P3→P4优先级出报告
  ↓
有P1/P2/P3？ → 修改 → 再审（最多2轮）
  ↓
只剩P4？ → 跳过，继续下一批
  ↓
2轮后仍有P1/P2/P3？ → 停下问冰哥
```

## 注意事项

1. 这不是自动注入机制——需要手动嵌入任务body或审核流程
2. 禁用词完整列表在 story-long-write 的 `references/banned-words.md`
3. 去AI味详细规则在 story-long-write 的"去AI味写作专项"段落
