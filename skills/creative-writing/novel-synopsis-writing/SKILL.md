# 番茄小说简介撰写指南

## 触发条件
- 用户要求写小说简介/书籍简介/作品简介
- 用户要求优化/改写/压缩现有简介
- 用户要求参考热门小说风格写简介

## 番茄简介规范

### 字数限制
- **硬限制：500字符**（含标点、空格、标签）
- 番茄后台会严格校验，超1个字都无法保存

### 必备元素

#### 1. 【标签】开头（番茄爆款标配）
```
【蒸汽朋克】【诡秘调查】【事务所办案】【群像升级】
```
- 3-5个标签，用【】包裹
- 标签用于番茄算法推荐匹配
- 标签计入总字数

#### 2. 短句为主
- 一句一个信息点
- 句子长度控制在15-25字
- 避免长复合句

#### 3. 金句钩子
- 开头第一句要有吸引力
- 用角色设定或反差制造钩子
- 例：「雾港有一家破事务所。老板杰克，四十岁，穷，收费二十铜币，不赊账。」

#### 4. 悬念递进
- 信息层层加码
- 从日常→异常→核心冲突→悬念
- 用省略号……连接转折

#### 5. 结尾留悬念
- 最后一句要有张力
- 例：「而他开的这家事务所，正好挡在深渊门口。」
- 例：「别人接委托，他接深渊。而深渊，也终于看见了他。」

### 禁忌
- ❌ 「新手第一本」「请多指教」「这本书不成熟」——负面开场劝退读者
- ❌ 过长的背景描述——读者没耐心看
- ❌ 剧透核心悬念——留白比说透更有吸引力
- ❌ 过于谦虚——番茄读者喜欢自信的作者

## 压缩原则（重要教训）

### 错误做法（2026-06-30血泪教训）
用户给了493字的简介，要求压到500字以内（实际只需微调）。
错误操作：把整个简介重写压缩，只保留162字，丢失了所有精华。

### 正确做法
1. **先确认用户意图**：是"压到500以内"还是"重写一个更短的"
2. **保留结构**：标签+开头钩子+递进+金句结尾
3. **只删冗余词**：不改变句子结构和节奏
4. **压缩后对比原文**：确保核心信息和金句都保留

### 压缩技巧
- 删重复信息（同一意思说了两遍）
- 删冗余修饰词（"非常"、"特别"、"很"）
- 合并同类句（两个短句可以合成一个）
- 删"的"字（"蒸汽与齿轮的城市" → "蒸汽齿轮之城"）

## 用户原创简介分析（2026-06-30）

用户自己写的简介比我给的所有版本都好，分析其优点：

```
【蒸汽朋克】【诡秘调查】【事务所办案】【群像升级】
雾港有一家破事务所。
老板杰克，四十岁，穷，收费二十铜币，不赊账。
别人鉴定古董，他鉴定污染、遗物、死人留下的秘密。
一开始，他只想靠接小案子混口饭吃。
直到一个女人抱着儿子的照片找上门。
失踪工人、蒸汽工厂、地下车间、活人实验，还有一枚自己转动的金齿轮……线索越查越不对劲。
杰克发现，自己能看见的不只是物品来历。
还有记忆、污染，以及神明留下的痕迹。
从那天起，雾港所有怪案都找上了门。
会哭的遗物、杀人的档案、七年前寄来的信、被神明注视过的城市……
所有人都以为杰克只是在查案。
只有他知道——
那些案子背后，有东西正在醒来。
而他开的这家事务所，正好挡在深渊门口。
```

**为什么比AI写的好：**
- 「别人鉴定古董，他鉴定污染、遗物、死人留下的秘密」——对比句式，一句话立住人设
- 「收费二十铜币，不赊账」——细节感，让角色有生活气息
- 「线索越查越不对劲」——口语化表达，比正式描述更有张力
- 「只有他知道——」——破折号留白，比直接说更有悬念
- 句子节奏：短→短→长→短→长→短，有呼吸感

## 工作流程

1. **了解作品信息**：题材、主角、核心冲突、世界观
2. **参考同类型热门简介**：在番茄小说搜索同类作品
3. **写初稿**：遵循上述规范
4. **字数检查**：用Python统计字符数（含标点和标签）
5. **用户确认**：可能需要多轮修改
6. **压缩时**：只删冗余，不改结构和金句

import re
text = "简介内容"
hanzi = len(re.findall(r'[\u4e00-\u9fff]', text))
total = len(text.replace('\n', '').replace(' ', ''))
print(f'纯汉字数: {hanzi}')
print(f'含标点总字符数: {total}')
