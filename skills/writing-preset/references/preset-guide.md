# 写作预设选择指南

## 如何选择预设模式？

### 问自己三个问题：

**1. 这次写作的任务类型是什么？**

| 任务类型 | 推荐模式 |
|----------|----------|
| 严格按大纲写正文 | Grounded |
| 日常更新/续写 | Classic |
| 探索新方向/试写 | Creative |
| 修改/润色已有章节 | Grounded |
| 大纲搭建/设定 | Creative |

**2. 对风格一致性的要求？**

| 一致性要求 | 推荐模式 |
|------------|----------|
| 必须高度一致 | Grounded |
| 基本一致即可 | Classic |
| 允许适度变化 | Creative |

**3. 需要多少创意自由度？**

| 创意自由度 | 推荐模式 |
|------------|----------|
| 严格遵循设定 | Grounded |
| 适度发挥 | Classic |
| 大胆探索 | Creative |

---

## 模式对比表

| 特性 | Grounded | Classic | Creative |
|------|:--------:|:-------:|:--------:|
| 温度 | 0.7 | 0.85 | 1.0 |
| 创意度 | 中 | 中 | 高 |
| 重复率 | 低 | 中 | 低 |
| 护栏频率 | 每3章 | 每5章 | 每7章 |
| 护栏严格度 | 严格 | 标准 | 适中 |
| 对话模板 | 严格 | 标准 | 灵活 |
| 上下文加载 | 完整 | 智能 | 相关 |
| 禁用词 | 零容忍 | 标准 | 偶尔可接受 |
| 段落长度 | 1-2句 | 1-3句 | 1-4句 |

## 场景速查

### 写《我在深渊开事务所》正文

| 卷/阶段 | 推荐模式 | 原因 |
|---------|----------|------|
| 第一卷（黄金三章） | Grounded | 开篇必须精准 |
| 第二卷（稳定期） | Classic | 保持一致性 |
| 第三卷（高潮期） | Classic | 平衡稳定与创意 |
| 第四卷（探索期） | Creative | 需要新元素 |

### 修改/润色

| 修改类型 | 推荐模式 | 原因 |
|----------|----------|------|
| 术语替换 | Grounded | 精确匹配 |
| 字数补充 | Classic | 自然扩展 |
| 风格统一 | Grounded | 严格一致 |
| 创意补充 | Creative | 鼓励新意 |

### 大纲/设定

| 任务类型 | 推荐模式 | 原因 |
|----------|----------|------|
| 卷级大纲 | Creative | 需要创意 |
| 细纲搭建 | Classic | 平衡 |
| 世界观设定 | Creative | 大胆想象 |
| 角色设定 | Classic | 稳定一致 |

---

## 快速切换

在看板任务body中指定：

```markdown
### 写作预设
- 模式：grounded | classic | creative
```

或在对话中说：

```
使用Grounded模式写作
切换到Creative模式
加载Classic预设
```

---

## 注意事项

1. **模式切换后需要新对话** — 类似SillyTavern，切换预设后建议开始新会话
2. **Grounded模式最适合番茄平台** — 番茄要求高一致性
3. **Creative模式适合探索** — 试写新元素时使用
4. **Classic模式是默认** — 不确定时用Classic
