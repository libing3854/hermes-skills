# Kanban小说写作：世界观约束与常见陷阱

## 1. 世界观红线约束（2026-06-25 教训）

问题：并行批量写作时，kanban worker忽略任务body中的世界观约束，生成完全错误的设定。

解决方案：
1. 任务body中必须包含明确的禁止词列表（红线词）
2. 每批完成后必须验证世界观正确性（grep红线词）
3. 发现跑偏→立即删除→重写
4. 用户清理流程：快照备份→隔离跑偏稿→从头重写

红线词模板：
⚠️世界观红线（违反即为废稿）：
- 地点=XX（禁止：A/B/C）
- 组织=XX（禁止：D/E/F）
- 技术=XX（禁止：G/H）

## 2. kanban worker文件名问题

问题：worker写文件时经常不带标题后缀（第XXX章.md而非第XXX章_标题.md）。
解决方案：每批完成后手动修复文件名。

## 3. Provider额度耗尽切换

问题：LongCat额度用完后写作任务blocked（HTTP 429）。
解决方案：切换到DeepSeek（lili profile）继续写。

## 4. 批量写作最佳实践

- 2-3章/批最安全，10章以上容易跑偏
- 每批完成后必须验证世界观、修复文件名、检查字数
- 发现系统性跑偏→快照→隔离→从头重写

## 5. 复验后禁用词修复工作流（2026-06-25 教训）

复验报告会列出残留的禁用词。修复分两类：

### 简单替换（直接patch，不走看板）
适用于：地名/组织名/技术名等纯词汇替换，不涉及动作描写。

标准替换表：
| 禁用词 | 替换为 | 示例 |
|--------|--------|------|
| 西区 | 城西旧工坊区 / 雾港西侧旧街区 | "西区的机械零件工坊" → "城西旧工坊区的机械零件工坊" |
| 中城区 | 东侧临时检查点 | "中城区检查站" → "东侧临时检查点" |
| 黑雾 | 浓雾 / 阴影 | "被黑雾染成的灰" → "被浓雾染成的灰" |
| 深渊 | （需根据上下文定制） | — |

### 动作戏重写（走kanban，不简单替换）
适用于：禁用词嵌入动作描写中（如武器名、战斗方式），简单替换会破坏角色设定。

**典型案例：短弩**
凯瑟琳是前警察，不能用短弩。但"短弩"出现在动作戏中（"左手按了一下腰侧——确认短弩还在"），不是简单词替换能解决的。

修复策略：
1. 读取上下文，理解角色当前的动作/状态
2. 用角色设定的装备替代：警用短棍、袖中小刀、手枪
3. 重写整个动作描述，保持节奏和氛围不变
4. 示例：
   - 旧："手指碰到弓臂的弧度" → 新："手指碰到棍柄的棱线"
   - 旧："她没有放松手对短弩的控制" → 新："她没有放松对腰侧短棍的留意"

### 判断标准
- 只是地名/名词替换 → patch直接改
- 涉及武器/战斗/角色能力 → 走kanban重写该段落
